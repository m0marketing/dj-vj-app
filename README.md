# DJ/VJ Studio

ブラウザだけで動く 2 デッキ DJ + 128 パッドサンプラー / ドラムマシン + 音に反応する VJ。
Next.js (App Router) 製で、Vercel にそのままデプロイできます。PWA としてホーム画面にも追加できます。

## 機能

### Mode / Theme / 演出 (ヘッダー)
**Mode = 曲の流し方 (DJ)**、**Theme = VJ で何を映すか**、**演出 = VJ をどう動かすか**。3 つは独立していて、どの組み合わせでも使えます (例: DevDay 2026 × キーノート = 会場向け、DevDay 2026 × フェス = パーティー)。

Mode:
- 🔥 **EDM**: フェス DJ の技。**Double Drop** (次の曲のドロップを今の曲のドロップと同じ小節に落とし、8 小節重ねてから抜く)、**ビルド → ドロップ**、**ブレイク → ドロップ** (出る曲がブレイクに入ったら次の曲のドロップへ 1 小節でカット)、ライザー / スネアロール自動、**エネルギーを上げ続ける選曲** (BPM・音量が少し上の曲を優先)
- 🎤 **サビ連発**: 各曲のサビだけを 2 小節で繋ぐ。長尺は中のサビを順に。Auto FX / Auto Hype 中
- 🎉 **パーティー**: 1〜3 分ごとにランダム切替、派手な繋ぎ、Auto Hype 強
- 🌙 **チル**: 曲を最後まで、32 拍の長いブレンド、演出なし
- 🎧 **クラシック DJ**: 頭から最後まで、16 拍ブレンド中心
- 🥁 **ドラムマシン**: 909 / 808 キットとステップシーケンサーでサンプラー + エフェクトだけでプレイ

Theme (VJ パネル上部にも同じ選択があります):
- **DevDay 2026**: 公式配色 + DevDay のビジュアルのみ。**Launch** (発表プロダクト名がフレーズごとにスラムイン → 日本語の一行がタイプイン、ブラケットが締まる) / **Swarm** (220 個の Dots が「DevDay」「[2026]」「OpenAI」「Codex」の文字に集合 → 次のフレーズで散開) / **Pulse** (巨大ブラケットがキックで脈動、拍番号、ダウンビートでリング、フレーズ頭で全画面カラースラム) / Circles / Title / Products / Ticker / Stack / Terminal / Brackets。プロダクトの文言は [DevDay 2026 recap](https://openai.com/ja-JP/index/devday-2026-recap/) に合わせています。キャプション「OpenAI DevDay [2026] Hackathon」
- **Neon** / **Classic** / **Minimal** / **Free (全部)**

演出 (VJ の動き方):
- **おまかせ (曲に合わせる)**: 曲のエネルギー (数秒で平滑化) で演出が変わる — ブレイク = シネマ、通常 = クラブ、盛り上がり / ドロップ = フェス。数値パラメータは補間、カットの種類 / 切替間隔は最寄りの演出に従う
- **フェス**: 4 小節ごとに絵が変わり、ドロップでレーザー + 紙吹雪 + フラッシュ、カメラ強め、ストロボ可
- **クラブ**: キックでズーム、8 小節ごとにカット、RGB ずれ・グリッチあり (標準)
- **シネマ**: ゆっくりしたカメラ、ディゾルブ、黒帯 (レターボックス)・グレイン・ライトリーク強め、16 小節ごとに場面転換、ストロボなし
- **キーノート**: 揺れ・グリッチ・ストロボなし、ディゾルブ / ワイプのみ、16 小節ごと、キャプション重視 (会場向け)
- **ミニマル**: 色と明るさだけが音に反応、32 小節ごとにゆっくり切替

**組み合わせの軸** (すべて独立、Look に保存):
- **Theme** (何を映すか) × **演出** (どう動かすか: おまかせ / フェス / クラブ / シネマ / キーノート / ミニマル / **カスタム**)
- **レイヤー 2**: 2 つ目のプリセットを重ねる (Shift + クリック)。合成モード スクリーン / 加算 / オーバーレイ / 乗算 / 差の絶対値 / 通常、不透明度、鏡。🎲 でランダム
- **色**: 曲のキー / 固定 / パレット (DevDay・ネオン・サンセット・オーシャン・ウォーム・モノ、8 小節ごとに次の色)
- **カスタム演出**: カメラ・揺れ・RGB ずれ・グリッチ・フラッシュ・グレイン・ライトリーク・ビネット・カットの長さ / 種類・切替間隔・黒帯・ストロボ可 をスライダーで

**Look (場面プリセット)**: Theme × 演出 × 絵 (固定 or 自動切替) × 色 × キャプション をひとまとめに保存 / 呼び出し。内蔵: ウォームアップ (Minimal × シネマ) / ピーク (Classic × フェス) / ブレイクダウン (Minimal × ミニマル × Rings 固定) / DevDay キーノート / DevDay パーティー / DevDay おまかせ / **DevDay レイヤー** (Tunnel × Swarm) / **サイケ** (Kaleido × Plasma 差の絶対値・ネオン) / **ディープ** (Starfield × Rings・オーシャン)。VJ パネルの「+ 今の状態を保存」で自分の Look を追加 (ブラウザに保存)。呼び出しは**次の小節頭に量子化**されるので、切替が音楽に乗ります。

**Now Playing**: 曲が始まるたびに左下へ放送風のローワーサード (NOW PLAYING + 曲名) を 7 秒表示 (常時表示 › で OFF 可)。

**安全**: 全画面フラッシュは演出に関わらず最大約 3 回 / 秒に制限 (光過敏への配慮)。

プリセットを手で選ぶとその絵に**固定**され (追従は色・明るさだけ動かす)、「切替 ON」に戻すと Theme の範囲で 8 小節ごと / ブレイク / ドロップに自動で切り替わります。

### DJ
- 2 デッキ (A / B)。**ズーム波形 (ビートグリッド表示・ドラッグでスクラブ)** + 全体波形 (クリック / ドラッグでシーク)
- CDJ 式 **CUE** (再生中: キューへ戻って停止 / 停止中: キュー設定 / キュー上で長押し: 試聴)、Play / Pause
- ジョグホイール: 停止中はスクラブ、再生中はテンポを一時的に前後 (ナッジ)
- **キーロック (マスターテンポ)**: AudioWorklet の WSOLA 方式ピッチシフト (重なるグレインの開始位置を相互相関で位相合わせ → こもり / コムフィルターなし、+1.5 dB のエアシェルフで補正) で、テンポを変えても音程を保つ (デッキの `Key` ボタン、既定 ON)。±0.3% 以内はバイパス
- **サビ (コーラス) マーカー**: 自動検出 / 手動設定、波形に表示、ワンタッチでジャンプ
- **🎧 ヘッドホンキュー**: Mixer › 🎧 ヘッドホン で出力先 (例: USB ヘッドホン) を選ぶと、デッキの 🎧 でその曲を**会場に出さずに**フェーダー前で確認できます。CUE / MASTER の混ぜ具合つき。実装は MediaStreamDestination + `HTMLMediaElement.setSinkId()` (Chrome / Edge / Safari 17+。Firefox は非対応で UI 非表示)
- **ボーカル検出**: 曲ごとに小節単位のボーカル存在度を解析 (声の帯域 300 Hz〜3.5 kHz のエネルギー比 × 持続性、曲内で正規化)。波形の上にピンクの帯で表示。Blend で**両方がボーカル区間**なら、入る曲の中域をベース入替まで −10 dB に抑え、入替後は出る曲の中域を下げて「歌がぶつからない」ようにします (ML なしのヒューリスティックなので目安)
- **スクラッチ**: `VINYL` ON で再生中にジョグを回すとスクラッチ (AudioWorklet の双方向プレイヤーで逆回転も再生、離した位置から続行)。自動パターン **Baby / Chirp / Transformer / Scribble / Stab / Rewind** は次の拍から始まり、終わると拍に合わせて元の流れに戻ります (テンポが崩れない)
- **キーシフト** (♭ / ♯、±6 半音): キーロック経由で音程だけを動かす。Auto DJ はキーが合わない次の曲を自動で ±1〜2 半音動かして相性の良いキーに (ハーモニックミキシング、細かい設定で OFF 可)
- **BPM 解析**: ピーク間隔のヒストグラム + オンセット包絡の自己相関で候補 (×2 / ×1/2 / ×3/2 / ×2/3 …) を検証し、1.5 拍間隔の誤検出 (138 → 92 など) を避けます。0.1 BPM 精度、整数 BPM に吸着。BPM 表示 → 「⟲ 再解析」でやり直し
- ピッチ (±50%)、ホットキュー ×4 (長押し / 右クリックで削除)、手動ループ (In / Out)、ビートループ (1/2/4/8 拍・グリッド吸着)、ループ ½ / ×2
- **ホットキュー・ループ・キューポイント・OUT 位置は曲ごとに保存**され、次に載せた時に復元
- 3 バンド EQ・LPF/HPF スイープフィルター・チャンネルフェーダー (ラベルタップ / ダブルクリックでリセット)
- 等パワークロスフェーダー・マスター・コンプレッサー
- 楽曲登録時に BPM・1 拍目の位置・キーを自動解析。BPM 表示をクリックして **×2 / ÷2 / TAP / 直接入力 / グリッド補正**
- `SYNC` は相手デッキの BPM に合わせ、相手が再生中なら**ビートの位相も揃える**
- 再生中のデッキへのロードは確認ダイアログで保護 (誤タップ防止)
- 残り 30 秒で時間表示が赤く点滅、Auto Follow / Auto DJ 有効時は自動ミックスまでのカウントダウンを表示
- マスター出力の録音 (`REC` → .webm / .m4a をダウンロード、経過時間表示)

### ミキサー
- **Transition**: Blend / Filter / Fade / Drop Swap / **Double Drop** / **Break → Drop** / Spinback / Echo Out / Reverb Out / Loop Roll / Cut / **Fade In** / Fade Out (8 〜 128 拍 = 2 〜 32 小節)。入る曲は**無音を飛ばし、相手デッキの小節の頭にサンプル精度で合わせて**スタート。BPM が ±16% 以内 (キーロック時) なら自動でテンポを合わせ (半分 / 倍速も考慮)、ブレンド中は 0.5 秒ごとにキックの位相ズレを補正します。離れすぎている曲は無理に合わせず、フェード / Echo / Reverb / Cut を選びます
- **MIC · ラップ / MC**: マイク入力チャンネル。声の加工 (そのまま / メガホン / ラジオ / ロボット (リングモジュレーター) / 低く −5 / 高く +6)、ピッチ ±12 半音 (キーロックと同じシフター)、テンポ同期 Echo、Reverb、コンプレッサー、**トークオーバー (Duck)** = 話している間だけ音楽を −8 dB 下げて自動で戻す。マイクは録音にも入ります
- **DJ テクニック (Hype)**: Echo Throw (1 拍だけエコーに投げる) / Filter Rise (4 小節のハイパス上昇 → 開放) / Gate ⅛ · 1/16 (テンポ同期ゲーター) を追加
- **Hype**: Build & Drop (マスター HPF で 8 / 4 小節ビルドアップ → 小節頭でドロップ、`Y`)、Crowd! (エアホーン + 歓声 + 演出、`U`)、**Beat Repeat** (マスター全体を 1 / 1/2 / 1/4 / 1/8 拍で刻む。次の拍の頭から捕まえる。押している間 / タップでラッチ)
- **フレーズメーター**: エネルギーバー + 8 小節フレーズ内の現在小節と拍、「次のフレーズまで N 小節 (秒)」。Build & Drop やループロールを狙った位置に当てられます
- **FX (押している間)**: HPF ↑ / LPF ↓ スイープ、Break (4 拍止めて DROP)
- **Effects (マスター)**: Echo (BPM 同期)・Reverb・Flanger。押している間 ON / 軽くタップでラッチ、Depth で深さ調整 (キー `G` `J` `K`)
- **Auto**: Auto Follow (次の曲をセットすると OUT 位置で自動ミックス)、Auto DJ、繋ぎ方 (auto = 曲ごとに最適な繋ぎを自動選択)
  - **Auto DJ の開始**: 「Auto DJ」ボタン、または Library の「▶ 選んだ曲で Auto DJ 開始」で、両デッキに曲をセットして再生を始め、以降は自動で A↔B を行き来します
  - **プレイリスト**: チェックした曲を名前付きで保存 (Library › プレイリスト › + 保存)。クリックで選曲対象に、ダブルクリックで名前変更
  - 細かい選曲設定 (対象 / 順番 / 相性 / 切替スパン / 入り位置) は Mixer › Auto › 「細かい設定」に収納 (Mode ボタンでまとめて設定可)
  - **選曲**: ライブラリ全曲 / **Library でチェックした曲のみ**、**ランダム** / 並び順。相性は「BPM + キー / **キー優先 (Camelot)** / BPM 優先 / 気にしない」から選択。同じ曲が続かない履歴付き
  - **🎤 サビだけ繋ぐ (サビモード)**: 各曲のサビ (自動検出 16 小節) だけを流して次々に繋ぎます。出る曲はサビの終わりの小節で切り替わり、入る曲は繋ぎ (2 小節) の分だけ手前から入るので**サビの頭が切替点にぴったり来ます**。繋ぎは勢いを落とさない Blend / Cut / Echo / Fade から自動選択
  - **サビ検出**: 小節ごとのエネルギー・明るさ・低域と、曲内の繰り返し (自己相似) から「音が一段上がって始まり、繰り返しが多く、途中に無音のない 16 小節」を選びます。**6 分を超えるファイル (DJ ミックス・アルバム) では 90 秒以上離れたサビを複数 (最大 40 箇所) 検出**し、サビモードではそれらを順番に巡回 (未再生のサビが多い長尺ほど選ばれやすい)。デッキの「サビへ」でジャンプして確認、「ここをサビに (8 / 16 / 32 小節)」で手動修正 (✎ 印)、「⟲ 自動」で再検出。波形上に黄色で表示
  - **A↔B の切替スパン**: 曲の最後まで / 長尺 (5 分超) のみ 2 分 / ランダム 1〜3 分 / 30 秒〜5 分ごと。曲の末尾の無音は自動で避けます
  - **入り位置**: 見せ場 (音量の大きい 8 小節の頭、無音の区間は避ける) から (既定) / 長尺のみ / 音が始まる所から
  - **プロ風の繋ぎ (Auto DJ)**: ミックスは出る曲の **8 小節フレーズの切れ目で終わる**ように開始時刻を合わせ、入る曲は**サビ / 見せ場がちょうどブレンド完了の小節に来る**ように手前から入ります。Blend は小節頭で**ベースを一気に入れ替え** (それまでは入る曲の低音をカット)、入る曲の高域はゆっくり開き、終盤は出る曲の中域を下げてボーカルの衝突を避けます。曲ごとの**ラウドネスを解析して ±6 dB で自動トリム**するので音量が飛びません。auto の繋ぎ方は基本 Blend (時々 Filter / Echo)、テンポが離れた曲は Fade / Echo Out — Cut / Spinback / Drop は手動専用
  - **セットプラン (時間 × 曲数)**: 「60 分 / 15 曲」のように入れて開始すると、1 曲の長さを **残り時間 ÷ 残り曲数** で配分し続け、時間が来たらフェードアウトして停止。**長いファイルは中のサビの数だけ「曲」として数え**、毎回別のサビから入ります。残り 45 秒を切ったら新しい曲は始めません
  - **セットリスト (曲順)**: Library で曲順を決めて (各行「＋」/ チェックをまとめて / プレイリスト ⇢)、「▶ この順で Auto DJ」。順番が尽きたらシャッフルに戻ります。プランと併用可
  - **Tempo Ramp**: テンポが 16〜30% 離れた曲は、再生中の曲を 8 小節かけて次の曲のテンポへ寄せて (キーロック) からブレンド。auto で自動選択
  - **ミックスアウトの位置**: 目標の 2 フレーズ以内にサビの終わりがあればそこで出る (セクションの切れ目)
  - **ビートグリッド**: オンセット包絡のコムフィルターで 1 拍目を 1 ms 精度で推定 (ダウンビート重み付き)
  - **イントロに合わせたブレンド長**: 曲ごとにイントロ (音量が低い冒頭の小節数) を解析し、頭から入る繋ぎではブレンドをイントロ内に収めます (歌 / ドロップが始まる前に繋ぎ終わる)
  - **ラウドネス = LUFS**: K 特性 (BS.1770 風) のゲート付き積分ラウドネスで測り、−14 LUFS を目標に ±6 dB でトリム (RMS より耳の感覚に近い)
  - **エネルギーカーブ (プラン)**: 「中盤ピーク / 上げ続ける / 波 / 気にしない」。時間の位置ごとの目標エネルギーに、BPM と音量の順位が近い曲を選びやすくします
  - **セットリストの時間見積もり**: 今の切替設定で再生した場合の合計と、プランの時間との差を表示 (緑 = ±2 分以内)
  - **♫ 相性順に並べ替え**: キューの 2 曲目以降を、BPM 差と Camelot の輪の距離が最小になる順に (最近傍 + 2-opt)
  - **始まりはフェードイン**: Auto DJ 開始や、無音の状態から曲を頭から再生するときは 2〜4 小節かけてフィルターを開きながらフェードイン (Mixer › Auto › 細かい設定で OFF 可)。Transition の「Fade In」でも手動で
  - **次にこの曲**: Auto DJ 中は Library の各行に「次▶」。押すと次の 1 曲がそれになり、待機デッキにすぐ差し替わります
  - **流した曲**: Library に再生履歴 (時刻付き) を表示
  - **エネルギー設計**: 「気にしない / 上げ続ける / 波」。上げ続けるは BPM・ラウドネスが少し上の曲を選びやすくします
  - **テンポはあなたが決める**: 再生中のデッキのピッチを動かすと、次の曲はその速さに合わせて入ります (曲本来の速さではなく「今のセットのテンポ」が基準)。ブレンド中にどちらかのピッチを動かすともう一方も追従。Mixer › Auto の「テンポ −1% / +1% / 0」でセット全体をまとめて調整。テンポを上げているときは合わせられる範囲も広がります (最大 ±25%)
  - 次の曲は終了の約 30 秒前にもう一方のデッキへ先読みされ、デッキ表示に「AUTO MIX カウントダウン ▸ 次の曲 (繋ぎ方)」が出ます
  - **Auto FX**: 繋ぎの瞬間にリバースクラッシュ / ライザー / スネアロール / ドロップインパクト / リワインドなどの内蔵サンプルと VJ 演出を自動で重ねます
  - 有効中はヘッダーにバッジ表示

### サンプラー (8 バンク × 16 = 128 パッド)
- キーボード `1-4 / Q-R / A-F / Z-V` で演奏、`F1-F8` / `-` `=` でバンク切替
- **ドラムマシン (16 ステップシーケンサー)**: 8 レーン (どのパッドでも) × 16 ステップ、アクセント、スウィング、パターン 4 スロット、house / techno / trap / breaks プリセット。デッキ再生中はそのテンポに同期し**次の小節頭から**走ります (`P` で再生 / 停止)
- **バンク G: TR-909 風キット** (Kick / Snare / Clap / Rim / HH / Ride / Crash / Tom ×3 / Cowbell / Clave / Maracas / Conga ×2)、**バンク H: TR-808 / トラップキット** (ロング 808 キック、808 ベース C / F / G / A、スネア、クラップ、メタリック HH、カウベル、ハットロール …)
- **内蔵キット 60 種以上**を初回起動時にブラウザ内で合成生成して自動配置 (ドラム / FX / パーティ系 / リミックスループ / EDM コーラスフレーズ / ビルドアップ / Wobble・Reese ベース / Trap Hats / チャント / Tape Stop / Vinyl Crackle …)
- パッドごとに **One-shot / Gate / Loop / Toggle**、ゲイン、ピッチ (±12 半音)、チョークグループ、カラー、VJ エフェクト、**波形トリム (スタート / エンド)**、試聴
- ループ系パッドは再生中の曲の **BPM・キーに自動で合わせて鳴る** (Auto Match)、拍 / 小節へのクオンタイズ
- サンプルはライブラリからドラッグ&ドロップで割り当て、または音声ファイルを直接パッドにドロップ
- **マイク録音 (開始 → 停止のトグル)** でその場でサンプル化して空きパッドに割り当て
- 読み上げパッド (テキストをブラウザ音声で再生)、`Esc` で全サンプル停止

### VJ
- マスター出力を解析して「レベル / 低域 / 中域 / 高域 / ビート / BPM」を抽出
- プリセット
  - Classic: Spectrum Bars / Pulse Rings / Particle Burst / Hyper Tunnel / Neon Grid / Beat Strobe / Laser Show / Disco Ball / Sunburst
  - New: **Oscilloscope / Kaleidoscope / Starfield Warp / Plasma / Big Type**
  - DevDay 2026: Circles / Title / Products / Ticker / Stack / Terminal / Brackets (公式配色 / neon / sunset)
- ワンショット FX (DROP / 紙吹雪 / レーザー / 花火 / テキスト …)、パッドにも紐付け可能
- **⚡ AUTO 演出** (1 ボタン): 音に合わせて色・明るさが動き、Theme の範囲で 8 小節ごと / ブレイク / ドロップに絵が切り替わり、**Director** (After Effects 風の自動モーショングラフィックス) がかかります: キックでパンチズーム、強い音でカメラシェイク、絵の切替時はズームスルー / ワイプ / スライド / ディゾルブ / フラッシュカット / スピン、ダウンビートで RGB ずれ (色収差)、ランダムなグリッチスライス、4 小節ごとのフラッシュフレーム、ライトリーク、フィルムグレイン、ビネット、ブレイク中は黒帯 (レターボックス) が閉じてドロップで開く。プリセットを押すとその絵に固定 (演出は続く)
- PC では VJ 列を広く表示 (ヘッダーの「⊞ VJ 大 / DJ 大」で切替)
- **♪ 音に合わせて色・明るさ** (既定 ON): 色相は曲のキー、明るさはエネルギー、ブレイク (静かな区間) では長い残像、ブレイク明けのドロップで DROP! 演出。**切替 ON** のときは Theme の範囲で 8 小節ごと / ブレイク / ドロップにプリセットも切り替え、手でプリセットを選ぶと固定
- 細かい設定: 時間で切替・左右対称・ドロップで爆発・定期的に紙吹雪など (控えめ / ふつう / 派手)・ストロボ許可 (光過敏対策)・色・強さ・ビート感度・残像
- **常時表示のキャプション (イベント名など) とロゴ画像** (プロジェクターにも同期)
- `/vj` を別ウィンドウで開けばプロジェクター用フルスクリーン出力 (BroadcastChannel で同期・F キーで全画面)

### ライブラリ
- 楽曲 / サンプルをブラウザの IndexedDB に保存 (サーバー不要)
- **追加時の保存先を「継続 / 一時」で切り替え**。一時はメモリのみでタブを閉じると消え (パッドの割り当ても自動で空になります)、行の「保存」ボタンで後から継続保存に切り替え可能。マイク録音も同様
- **内蔵 (デフォルト) の削除**: 内蔵サンプルは「内蔵を選択」→ 削除、デモ曲は「デモ曲をすべて削除」、キャッチフレーズのパッドは「パッドを空にする」。削除したものは記憶され、内蔵キットの更新があっても復活しません。戻したいときは ⋯ › 「内蔵キット / デモ曲を追加」(削除済みも再生成)
- **サンプルの選択削除**: サンプルタブの各行にチェック。「表示中を全選択 / 未使用を選択 (どのパッドにも無いもの) / 一時を選択」→「選択した N 件を削除」。各行にどのパッド (A3 など) に割り当て中かを表示。削除は 6 秒間まとめて「元に戻す」可 (パッドの割り当ても復元)
- 検索、並び替え (追加順 / 名前 / BPM / キー)、**キー相性マーク (Camelot)**、試聴 (デッキに載せると自動で止まる)、名前変更 (ダブルクリック)、デッキへのロード、削除 (確認 + **6 秒以内なら「元に戻す」**。サンプル・プレイリストも同様)
- **バックアップ (.zip) の書き出し / 読み込み**、ストレージ使用量と永続化リクエスト (`⋯` メニュー)

### デモ曲 (初回起動時に自動生成)
- Kygo 風トロピカルハウス「Tropical Sunrise」(102 BPM)、Avicii 風プログレッシブハウス「Levels of Light」(126 BPM)、チル「Firestone Nights」(96 BPM)
- 著作権のある実曲は同梱できないため、Web Audio でその場で合成したオリジナル曲です。本物の楽曲は `+ 追加` から登録してください
- 生成ロジックは `src/lib/audio/synth/songs.ts` (コード進行・リフ・メロディを差し替え可能)

サーバー側の処理は一切無く、すべてクライアントで完結します。

## ヘルプ / UI

- ヘッダーの **? ヘルプ** に「はじめに / デッキ / ミキサー / サンプラー / ライブラリ / VJ / キーボード」のガイド。各パネル見出しの **?** からそのページに直接飛べます (ツールチップが読めないタッチ端末向け)
- 通知は最大 3 件まで重ねて表示 (エラーは 6 秒、成功 / 情報は 3 秒)。削除系の通知には「元に戻す」ボタン
- 何も再生していない時の Blend / Fade Out / Build & Drop は実行せず、理由を通知します
- タッチ端末 (pointer: coarse) ではボタン・タブ・スライダーが 40px 以上になります
- ヘッダーの「AUTO FOLLOW / DJ ON」バッジはクリックで OFF にできます
- **本番モード (Tab / ヘッダーの ▶ 本番)**: 大きな文字の操作盤。NOW (曲名・BPM・キー・残り・**切替までの秒数**・繋ぎ方) / NEXT (次の曲、キューの続き、「⟳ 次を選び直す」「▶ 今すぐ繋ぐ」) / マスター VU + フレーズメーター + 大きなクロスフェーダー / ■ 中止・Fade Out・Build & Drop・Echo Throw・Crowd! / Look ボタン。プランの進捗と時計つき
- **🎹 MIDI コントローラー (MIDI ラーン)**: ヘッダーの 🎹 MIDI → 接続 → 割り当てたい機能の「ラーン」を押してつまみ / ボタンを動かすだけ。72 のターゲット (クロスフェーダー・Master・デッキの ▶ / CUE / SYNC / Volume / EQ / Filter / Pitch / HOT 1〜4 / Loop / Scratch、パッド 1〜16、Hype 系、Look 1〜10、本番モード)。フェーダーは CC、ボタンはノート (押している間だけ効くものにも対応)。割り当てはブラウザに保存 (Chrome / Edge)
- **レイヤー 3 (画像 / 動画)**: VJ パネルの「レイヤー 3」で PNG / JPG / MP4 / WebM を選ぶと、生成ビジュアルの上に合成 (合成モード・量・全面 / 全体表示・拍で脈動)。ブラウザ内 (IndexedDB) に保存、プロジェクター窓にも出る、バックアップにも含まれる
- **キック位相の実測補正**: ブレンド中、約 6 秒ごとに両デッキの低域オンセット包絡 (実際の音) を相互相関して、グリッド推定の誤差 (10〜30 ms) を測り、位相合わせループに反映。合成キックで 40 ms ズレを ±8 ms 以内で検出 (`npm test`)
- **ストレージ**: 曲 / サンプル / 設定 / Look / キュー / 素材は IndexedDB。初回の継続保存時に永続化 (`navigator.storage.persist()`) を自動リクエスト、使用量 85% 超で警告、容量不足 (QuotaExceeded) は「何を消す / 一時にする」を案内。バックアップ (.zip) に曲・サンプル・パッド・設定・ロゴ・素材・MIDI 割り当てを含む
- **波形の直接編集**: Shift + ドラッグでサビ範囲を指定 (小節に吸着)、右クリックで OUT を置く / もう一度で消す
- **新しいキー**: T = Echo Throw、I = Filter Rise、O (押している間) = Gate ⅛、N = Baby Scratch、Shift + Enter = Double Drop、Backspace = ミックス中止、5〜9 / Shift + 5〜9 = Look 1〜10、Tab = 本番モード
- **出力保護**: マスター最終段にリミッター (天井 −1 dBFS、20:1、1 ms) + ソフトクリッパー。+12 dB の過大入力でもピーク 0.98 以下 (PA をクリップさせない)
- **セッション復元**: デッキの曲と位置・クロスフェーダー・Auto DJ・プランを 5 秒ごとに保存。リロード / クラッシュ / 誤って閉じた後、30 分以内ならヘッダーの「↻ 前回の続きから再開」で続きから (再生中だった曲は 2 秒のフェードインで再開、プランの残り時間も引き継ぐ)
- **解析の分散実行**: サビ / イントロ / ボーカル / LUFS の解析はアイドル時間に 1 つずつ実行 (長尺ファイルを載せた時の 0.5 秒のフリーズを解消)
- **テスト**: `npm test` (Node 組み込みの test runner、依存追加なし) — キー互換 / Camelot / キーシフト、演出パラメータの補間、zip の往復
- **パネル単位のエラー境界**: どれか 1 つのパネルで表示エラーが起きても、他のパネルと音はそのまま。「再試行」で復帰
- マスターのフィルター (HPF / LPF) やビートリピートがラッチされたままだとヘッダーに **⚠ LPF ON — 解除** が点滅します (クリックか Esc で解除。Esc は FX センドも全部切ります)
